# ML Foundation — аудит, протокол и два baseline

Статус: **завершён 2026-10-21** после вердикта независимого ревью R2 **APPROVE / READY** по HEAD `08fb61dc0e4dd3fd5650bd8c74110fcb6eff4106` и принятия владельцем. Изначальный план назывался ML-1 и объединял работы, которые обновлённая [дорожная карта](../../ML_PLAN.md) обозначает ML-1 Data Audit/EDA, ML-2 Validation Protocol и ML-3 Baseline Models.

## Цель

Создать воспроизводимый ML foundation: подтверждённый аудит, протокол валидации, Logistic Regression и CatBoost на одном разбиении, реальные метрики и загружаемые артефакты.

## Объём

Аудит TRAIN/TEST/text; поиск признаков возможной утечки; разделение групп одинаковых векторов примерно 80/20 со стратификацией групп; baseline только по таблице; проверка сериализации. Текстовая модель, подбор гиперпараметров и submission относятся к следующим ML-этапам; приложение разрабатывают другие команды.

## Критерии завершения

- Отчёт аудита различает измеренное и неизвестное; схема TRAIN/TEST проверена.
- Development/holdout и seed сохранены; идентичные векторы признаков не пересекают split; index/target исключены из X.
- Logistic Regression и CatBoost обучены либо зафиксирована конкретная техническая причина невозможности.
- ROC-AUC, Average Precision, время и конфигурация записаны без округления «до цели».
- Сохранённые модели дают тот же прогноз после загрузки на контрольных строках.
- Кеш привязан к источнику, схеме и версии преобразования; повреждение и незавершённая сборка обнаруживаются; полное соответствие TRAIN проверено отдельно от быстрого контроля повторного использования.
- Быстрые синтетические тесты проверяют split, границы предобработки, схему, повреждение артефактов и повторяемость прогнозов.
- Проверены Markdown-ссылки, Git diff/check/status; результат передан владельцу для принятия.
- Подготовлен [review package](../../REVIEW_PACKAGE_ML_FOUNDATION.md); результаты независимого ревью и решение владельца внесены в этот план перед закрытием.
