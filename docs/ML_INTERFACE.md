# Реализованный контракт ML-компонента

С 2026-10-21 реализован переносимый `BankruptcyPredictor` в `ml/inference.py`. Полный действующий контракт, пример, ошибки и установка — [ML_HANDOFF](ML_HANDOFF.md). Ранее проектировавшийся `PredictionResult` не используется как возвращаемый объект Python API: `predict` возвращает `float`, `predict_batch` — `list[float]`. Backend добавляет `model.model_version` в свою обёртку ответа.

Вход — ровно 1367 обязательных `feature_0`…`feature_1366`, конечные real numeric values в пределах float32. Bool/строки/None, NaN/Inf, пропущенные и лишние ключи отклоняются. `0` и `-1` сохраняются; импутации/масштабирования нет. Порядок всегда из schema, не порядок ключей словаря. `index` передаётся отдельно и не является признаком или способом автоматически найти features.

`load(model_dir)` проверяет SHA-256, схему, версии numpy/LightGBM и фактические параметры; обучение отсутствует. `predict(features, text_counts=None)` и `predict_batch(records, text_counts=None, batch_size=256)` сохраняют порядок. Невалидная запись отклоняет весь вызов без частичного результата. Reserved text counts — mapping слово → неотрицательная целая частота; текущая tabular модель их не использует и возвращает тот же score при None.

Выход — положительный score в [0,1], калибровка не подтверждена. Нельзя объявлять индивидуальную вероятность известного горизонта, risk level, percentile или объяснения без соответствующей проверки. Анонимные признаки не позволяют обещать ручную форму с бытовыми полями. Время формирования признаков/текста и горизонт события неизвестны. Необязательный текст может использовать только новая подтверждённая версия пакета с точным tabular fallback для отсутствующего текста.
