# Независимая проверка существенных изменений

Для каждого этапа автор предоставляет review package: ID и название, цель и критерии принятия, ветка, base/head SHA при наличии, ссылка на PR/compare, изменённые файлы, реальные проверки и метрики, параметры и seeds, расположение артефактов, ограничения и вопросы владельцу. Публикация Git-снимка требует разрешения владельца согласно [WORKFLOW](WORKFLOW.md).

ChatGPT в отдельной сессии как независимый ML reviewer читает фактические файлы, опубликованный Git diff и пакет проверки, а не доверяет отчёту автора. Он проверяет критерии активного плана, отсутствие утечек (target/index, предобработка, текст, повторы и субъекты), сопоставимость метрик, сохранение моделей, согласованность документов и безопасность данных. Замечания: blocker, important, minor; для каждого — место и минимальное исправление. Вердикт: READY или NOT READY.

Автор исправляет blocker/important и повторяет относящиеся проверки; reviewer сверяет обновлённое состояние. Если reviewer недоступен, в плане пишется «независимая проверка не проводилась». Самопроверку нельзя назвать независимой. Итог ревью и решение владельца фиксируются в execution plan. Закрытие плана после существенного изменения требует принятия владельцем.
