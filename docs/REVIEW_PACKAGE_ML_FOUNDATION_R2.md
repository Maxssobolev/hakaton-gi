## Остаточные ограничения

- Быстрое повторное использование доверяет манифесту, созданному кодом проекта; намеренная одновременная подмена и файлов, и манифеста выявляется только полным source-to-cache проходом `ml.verify`. Этот проход читает весь TRAIN и требует доступ к исходнику.
- Атомарна публикация манифеста, а не всех трёх файлов одновременно. Прерванная замена оставит несовпадение хэшей, которое обнаружит следующий запуск и пересоберёт кеш. Параллельные процессы сборки одного каталога не предусмотрены.
- Полная проверка формата текста отложена до ML-5; семантика анонимных признаков, время их формирования и независимость субъектов остаются неизвестными.
- Старый CLI-вызов без `--run-id` сохраняет прежнее поведение для воспроизводимости ML-1. Новые эксперименты обязаны использовать уникальный ID; runner ML-4 ещё не реализован.
- Holdout уже просмотрен в baseline, поэтому будущий подбор остаётся внутри development. Калибровка, финальная модель и inference package ещё не готовы.
